TrustHire AI

Fraudulent Job Posting Detection System

TrustHire AI is a Machine Learning and Data Science project focused on detecting potentially fraudulent job postings. The system analyzes job-posting information and learns patterns associated with legitimate and fraudulent postings using numerical, categorical, and text-based features.

The project includes data auditing, cleaning, exploratory data analysis, feature engineering, categorical encoding, and class-imbalance handling. A Streamlit interface is being developed to allow users to submit job-posting information and receive a fraud prediction along with selected risk indicators.
